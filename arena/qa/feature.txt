Add custom slash commands to the TUI. A file `.awl/commands/NAME.md` in the project root, or `~/.config/awl/commands/NAME.md`, makes `/NAME` send that file's text as the user's message (the project's file wins when both exist). Text typed after `/NAME ` is appended to the message on a new line. Built-in commands keep priority over files with the same name. Show the custom commands in the Tab picker after `/` (src/tui.zig: `commands`, `completeCommand`) and in /help. Add a check to tests/tui.py that a custom command sends the file's text. Document it in README.md. Run `zig build test`, `zig build e2e` and `bash tests/check.sh`; all must pass.
